# Gradient Descent

Gradient descent is an optimization algorithm used to minimize a loss function.

The basic update rule is:

θ = θ - α∇J(θ)

Where:

- θ represents model parameters.
- α is the learning rate.
- ∇J(θ) is the gradient of the loss function.

The gradient points in the direction of steepest increase in the loss. Therefore, gradient descent updates the parameters in the opposite direction of the gradient.

The process is repeated until the loss is minimized or the model converges.
